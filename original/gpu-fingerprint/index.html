Numeric GPU Fingerprint

Puts a fixed set of floating-point expressions to this device's GPU, through WebGPU compute shaders and through WebGL 2 and WebGL 1 fragment shaders, reads back the raw bits, and compares them with the correctly rounded answer. The sequence of results is a signature of the GPU, driver and interface. It is read from the GPU's numerical output, not from any name the browser reports, and it is not a canvas read. Each of the three is run in two modes, split (every expression in a shader of its own) and combined (all of them in one shader), because a compiler can give an expression different bits depending on the code around it; the card says when the two differ. For comparison, two classic canvas 2D fingerprints are taken as well, this page's own and the BrowserLeaks canvas test, each with its own timing, and the page records when a browser blocks any of the four interfaces.
